# OrçaFlow · Ateliê de trabalho

## Direction

Replacement of the original dark-rail / purple dashboard. Operate mode: familiar web controls, clear tasks, one coherent visual system. The user authorized the redesign; the existing screenshot is an anti-reference for composition.

Grounded candidates considered: a daily planner; commercial stationery; an independent studio's working identity; a service directory; a workshop order book; a small-business catalogue; a typographic wayfinding program. The concept seed assigned the third candidate: the independent studio's working identity. Reference: seed:36f163353496abde. This contributes palette, humanist type, compact rhythm and an alignment signature; it does not turn the application into a printed artifact.

The catalog challengers were evaluated against nontechnical users and task clarity. The plate-section discipline contributes consistent alignment; the sleeve's coded controls, center-rail apparatus, guide-map lobes, dense event catalogue and darkroom overlays are declined because their visual metaphors obscure familiar business controls. No catalog ornament is copied.

## Tokens

- Warm paper ground `#f5f4ef`, content white `#ffffff`, forest text `#203d32`.
- Muted text `#5f6b62`, borders `#d9ded7`, quiet sage `#e8eee7`.
- Primary action forest `#285342`; rust `#a3482f` for overdue work and errors; amber `#865b14` for warnings.
- One self-hosted humanist sans, Public Sans; native sans fallback.
- Text: 14, 16, 18, 24, 32 px; tabular numbers for business amounts.
- Spacing: 4, 8, 12, 16, 24, 32, 48 px. Controls minimum 44 px high.

## Composition

Top navigation, bounded working area, page title describes the task. A working list leads the day view. Financial totals are a compact supporting definition list, not oversized metric cards. Empty states explain the first action. Quote creation is a full page with an adjacent summary and familiar labeled inputs.

The signature is the shared alignment of dates, customer names and money across lists and the proposal editor, with a small rust dot in the wordmark. No decorative charts, gradients, icon tiles, slogans, floating blobs, dark side rail or duplicated tab navigation.

## Behavior

Visible focus rings, explicit labels, keyboard-operable dialogs, loading and error feedback. User data never comes from localStorage. Browser authentication is separate from the business database. All writes return saved feedback and server errors stay readable.

## Responsive

At 900 px supporting columns stack. At 640 px navigation gains a second row, tables become labeled record rows, the quote summary follows the editor, and actions remain reachable. Respect reduced motion. Test desktop, narrow desktop and mobile with real and empty data.

## Client portal

The client receives a document-led page with the provider identity and fixed proposal, a clear response form, payment status separated from approval, conversation, and fiscal documents. It inherits the same type, palette and controls and has no management navigation. Names entered through a link are described as informed names, not verified identities. Payment test mode remains explicit after every result. Fiscal upload is labeled as delivery of an already-issued document.
